## 一、系统总体架构

`blades-stock` 采用 **Go + Wails v2 + Vue 3 (Naive UI)** 的高性能多进程桌面架构：
- **Go 后端**：负责多源行情接入（Sina、TDX、Eastmoney、AkShare）、纯 Go 高并发量化数学运算、VectorBT 矩阵回测、SQLite WAL 存储以及 Blades Agent 调度；
- **AI 智能层**：基于 Go-Kratos Blades 框架深度定制，融合多模型容灾、MCP 协议扩展、Prompt 模版引擎与思维链推理；
- **Vue 前端**：轻量级高性能图表渲染（Lightweight-Charts、ECharts），沉浸式暗黑/亮色自适应，多维智能抽屉及全局浮动 AI 助手。

## 二、底层 AI 基础设施与大模型引擎

### 1. 多模型自动回退容灾机制 (`fallback_provider.go`)
- **多模型优先级队列**：支持按配置顺序组合主备模型（如 MiniMax、DeepSeek、OpenAI、Claude、Qwen、Ollama）；
- **故障自愈**：主模型遇网络超时、Token 额度超限、429 限流或 5xx 故障时，自动无缝切换到备用模型重试，保障研报生成与实时盯盘 0 中断；
- **日志审计**：记录模型调用链路、响应耗时与故障转移原因。

### 2. 透明工具规范自愈中间件 (`chat_model_factory.go`)
- **OpenAI 兼容协议强化**：拦截下发给 LLM 的 tools payload，自动为参数为空的工具补全标准 `{"type": "object", "properties": {}}`；
- **防崩溃保障**：彻底杜绝 MiniMax 2013 等“函数参数为空”的拒答异常。

### 3. 上下文滑动窗口与 Token 预算 (`sliding_context.go` & `token_budget.go`)
- **滑动截断机制**：对历史多轮对话动态评估 Token 占用，优先保留系统提示词、核心量化数据与近 3 轮交互；
- **思维链分离**：将模型的内部推理链 (`[STATUS]` 与 Reasoning) 提取并收拢到折叠标签中，研报正文保持干练纯净。

### 4. Agent 记忆与自我反思进化 (`blades_agent_*.go`)
- **量化回测记忆库**：记录历史推演成功率、用户交易偏好；
- **反思机制**：定期对比 AI 预判与实际收盘走势，形成策略修正参数。

## 四、量化核心策略技能体系 (Quantitative Skills)

将业界顶尖投研策略转化为确定性量化代码，杜绝单纯依赖大模型胡乱猜测：

### 1. Skill ID 7: ETF 21 日加权动量矩阵轮动 (`etf_momentum.go`)
- **纯 Go 数学运算**：
  $$\text{Score} = 0.5 \times R_{5} + 0.3 \times R_{10} + 0.2 \times R_{21}$$
- **均线多头强力过滤**：价格必须站上 20 日均线且 20 日均线保持向上；
- **刚性风控体系**：
  - 8% 追踪止损线（保护本金）；
  - 15% 动态分批止盈线；
- **研报呈现**：输出 ETF 评分榜单、进攻/防守仓位配比与调仓信号。

### 2. Skill ID 4: Serenity 产业链与产业生态深度拆解 (`TriggerSectorAnomalySerenityAnalysis`)
- **微观瓶颈挖掘**：供需错配、高毛利卡点、卡脖子环节深度剖析；
- **产业龙头定价权**：拆解客户集中度、上下游议价权及技术壁垒；
- **板块联动打通**：在资金流向图、板块排行榜上一键发起“🔬 拆解”，直达研报中枢。

## 五、3D 量化个股智能诊股与预测闭环

### 1. 3D 量化评分引擎 (`stock_diagnosis.go`)
从三大立体维度评估标的质地与爆发力（满分 100 分）：
1. **技术面动量 (40分)**：均线排列（MA5/10/20/60）、RSI 强弱区、MACD 金叉死叉与量能配合；
2. **资金面博弈 (35分)**：主力净流入、超大单异动比例、筹码集中度与龙虎榜热钱；
3. **基本面与安全边际 (25分)**：动态 PE/PB 分位数、ROE、估值折溢价与行业相对强度。

### 2. 预测记录与闭环回溯 (`SavePredictionRecord` & `CheckPredictions`)
- **信号存档**：生成预测时记录：标的代码、当前价格、预测方向（看多/看空/震荡）、置信度与目标区间；
- **自动对账**：到达目标周期（T+3/T+5/T+10）时自动拉取收盘价，核算胜率、盈亏比与最大回撤，沉淀为量化记忆。

## 六、VectorBT 向量化回测与量化工具矩阵

### 1. 纯 Go 原生向量化回测引擎 (`backend/quant`)
- **零依赖极速计算**：无需启动 Python 即可在内存中完成 10 年级别日线指标矩阵与买卖信号模拟；
- **支持经典指标策略**：双均线金叉/死叉、MACD 突破、布林带均值回归、RSI 超买超卖。

### 2. Python VectorBT 沙箱环境 (`vectorbt_sandbox.py`)
- **专业组合回测**：支持多资产组合、动态头寸调整与蒙特卡洛压力测试；
- **回测指标输出**：年化收益率 (CAGR)、夏普比率 (Sharpe Ratio)、索提诺比率 (Sortino)、最大回撤 (Max Drawdown)。

### 3. Agent 工具链体系 (`tools/`)
AI 对话助手可在对话过程中自主调用以下工具获取确定性数据：
- `RunVectorizedBacktest`: 触发向量化策略回测；
- `DiagnoseStock3D`: 获取个股 3D 量化诊断评分；
- `GetPureGoETFMomentum`: 查询 21 日加权动量评分矩阵；
- `StockKlineData`: 查询标准化前复权 K 线与历史分时；
- `HotMoneyChip`: 龙虎榜席位与主力资金流动监控；
- `FinancialReports`: 财报三张表核心指标透视。

## 九、个人实战研究中心「三步精简闭环」功能矩阵

针对个人交易爱好者的实操痛点，系统深度升级了「研究中心」三大核心模块，形成极简实用的实盘辅助闭环：

### 1. 连板梯队（`UplimitLadder.vue`）—— 情绪红绿灯与接力推演
- **量化情绪红绿灯**：根据炸板率（$< 25\%$ 进攻绿灯，$\ge 45\%$ 退潮红灯，其余震荡黄灯）直观显示盘面投机温度与安全级别；
- **一键 AI 接力推演**：提取最高板龙虎、各高度梯队家数、炸板率与所属热点，秒级生成《游资接力推演简报》，提示断板风险与低位首板补涨逻辑。

### 2. 异动监控（`stockChangesMonitor.vue`）—— 一键归因排雷与多维穿透
- **单股 `[⚡ 排雷]` 行级操作**：针对单只盘中拉升或跳水股票，结合行业/概念一键进行游资意图辨析、利空排雷排查与防套止损建议；
- **全局 `[⚡ AI 异动大盘全景透视]`**：顶部一键聚合当日主流异动热点分布，辨析主力资金主攻方向与脉冲陷阱；
- **多维下钻**：支持行内直接弹出多周期 K 线图（`StockLightweightKlineChart`）与 3D 量化诊断抽屉（`StockDiagnosisDrawer`）。

### 3. 交易日志（`TradingRecordManager.vue`）—— AI 纪律体检与胜率复盘
- **单笔 `[🩺 AI体检]`**：提取成交价格、现价、盈亏率、预设止盈止损、入场理由与心态备注，由 AI 交易教练从纪律合规评分（0~100分）、知行合一排查、进化建议三个角度进行 150 字快速诊断；
- **全局 `[📋 AI 账户纪律体检]`**：自动核算真实胜率、平均盈亏比（赔率）、最大胜负典型案例，一键生成对冲基金风控视角的《个人交易系统全面诊断报告》，输出 3 条红线防爆仓军规；
- **多入口协同**：在操作列、顶部工具栏、编辑日志弹窗底部均设有一键体检入口。

### 4. 选股研究池（`SelectStock.vue` & `AllStockList.vue`）—— 指标/形态 AI 信号共振推演
- **单股 `[⚡ 推演]`**：针对技术指标（如 MACD 金叉、均线多头、布林突破）或量价形态（连涨/连跌突破）匹配出的个股，分析量价虚实、关键买点与止损线、主力诱多排雷；
- **列表全局 `[⚡ AI 策略/形态共振推演]`**：一键聚合筛选池代表标的与板块归属，研判是否存在主线板块协同共振攻势，抑或是分散脉冲假突破，给出仓位控制建议；
- **全链路穿透**：集成 3D 量化诊断抽屉（`StockDiagnosisDrawer`）与多周期 K 线弹窗，实现“指标初筛 -> AI 推演 -> 3D 评分下钻”一站式闭环。

### 5. 自选股与持仓风控（`stock.vue`）—— 盘前一键综合排雷诊断
- **自选与持仓分级排雷**：在自选股分组顶部提供 `⚡ 盘前自选股一键综合诊断 / 排雷` 按钮，自动聚合当前分组内全部标的的现价、涨跌幅、持仓成本与盈亏比例；
- **三色安全清单输出**：
  - 🟢 **进攻/重点关注**：多头趋势向上、主线板块共振、浮盈格局标的；
  - 🟡 **防守观望/止盈**：逼近强阻力位、高位量价背离或缩量滞涨标的；
  - 🔴 **破位预警/果断止损**：跌破关键支撑、浮亏扩大、存在解禁/业绩雷区标的；
- **盘中盯盘红线**：输出今日焦点盯盘标的与坚决禁止冲动追高标的，守护个人交易纪律。

## 结语与维护指引

- **二进制规范**：统一输出至 `build/bin/blades-stock.exe`；
- **数据一致性**：SQLite 保持单写连接池与 WAL 模式，避免锁库；
- **AI 幻觉控制**：坚持“**纯 Go 数学计算出硬指标，LLM 负责逻辑归纳与推演**”的原则，保证量化建议的可靠性。
