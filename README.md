# Blades Stock — 智能投研桌面助手

Blades Stock 是面向量化投资与投研人员的桌面级智能助手，把大语言模型（LLM）与量化回测、资金流向、技术形态与可执行系统联动能力结合，提供可交互的 3D 个股诊断、AI 投研对话与自动化交易/监控联动。

[项目仓库](https://github.com/huch16/blades-stock) • 语言：Go + Vue • 许可：GPL-3.0

---

亮点一览

- 即点即用的 AI 投研助手：支持多轮对话、深度分析与 Agent 自动动作（页面导航、打开诊断、弹窗提醒等）。
- 3D 个股量化诊断：量化回测（VectorBT）、资金筹码与技术形态三维评分，输出风险、目标价与建议。  
- 向量化技能与语义检索：Embedding 驱动 Skill 匹配，将自定义技能注入 Agent 提示；支持多模型容灾。  
- 可扩展工具（MCP）：通过 MCP 加载远程工具（如外部数据源、策略服务），并支持白名单与超时保护。  
- 桌面级体验：基于 Wails 的桌面包装，UI 使用 Vue + Naive UI，支持快捷诊断抽屉与 K 线可视化。

---

为谁设计？

- 投研团队：快速生成结构化研报、历史回测验证与操作建议。
- 量化策略工程师：一键向量化回测与策略性能概览。
- 个人投资者：可视化诊断与 AI 建议，配合告警实现自动监控。

---

核心功能（产品角度）

1. 交互式 AI 投研助手
   - 支持自然语言提问、跟进询问与导出行动（Agent Actions）。
   - 提问可触发系统联动：打开指定股票诊断、跳转页面或触发风控告警。

2. 3D 个股量化诊断
   - 回测维度（策略胜率、盈亏比、夏普等）、资金维度（主力净买入、超大单占比）、技术维度（均线、ATR、乖离率）。
   - 输出综合评分、建议（买入/观望/卖出）、目标价/止损与主要风险项。

3. 向量化 Skill 与语义检索
   - 对话前通过 Embedding 检索相关 Skill（策略、行业、研究模板），将 Skill 指令注入模型提示，提升输出质量与可执行性。

4. 可扩展的工具生态（MCP）
   - 支持将外部工具注册为能力（例如实时行情、爬虫、回测服务），Agent 执行时可按需调用。

5. 桌面级联动与告警
   - 支持本地事件总线（AgentControlBus），前端监听 agent:action ��执行页面级联动或本地通知。

快速体验

1. 克隆仓库

```bash
git clone https://github.com/huch16/blades-stock.git
cd blades-stock
```

2. 启动后端（开发）

```bash
go mod download
go run ./...
```

3. 启动前端（开发）

```bash
cd frontend
npm install
npm run dev
```

4. （可选）使用 Wails 打包/运行桌面应用

```bash
# 需安装 wails
wails dev
```

注：项目默认分支为 dev。开发环境建议使用 Go 1.26+ 与 Node.js 16+。

---

安全与合规

- 数据与 API Key：请在生产环境通过 CI/Secret 管理所有密钥，不要将敏感信息写入源码。  
- Agent 输出中的自动动作（agent-action）在后端有安全过滤（会剔除示例占位符与空 payload），前端在触发前也会验证目标股票是否有效，避免误触发自动操作。

---

部署建议（企业/团队）

- 将后端部署到内网服务器，前端可打包为企业桌面客户端或通过内部 CDN 发布。  
- 建议接入企业 Embedding 服务与统一身份认证（SSO），并用数据库管理 MCPServer 与 Skill 白名单。
