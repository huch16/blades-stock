### 核心动量公式
1. y = log(close[-21:]) — 取最近21个交易日收盘价的对数
2. x = arange(21); weights = linspace(1, 2, 21) — 越近权重越高
3. slope, intercept = 加权最小二乘法回归 y = a*x + b
4. annualized = exp(slope * 250) - 1 — 年化收益率
5. R² = 1 - Σw·(y-ŷ)² / Σw·(y-ȳ)² — 加权R²。ȳ使用未加权均值（对齐聚宽np.mean(y)）。注意：R²不做[0,1] clamp，允许负值（震荡序列时负R²进一步压低排名）。
6. score = annualized × R² — 最终动量得分

### 多窗口动量融合（MultiWindowMomentumScore）
当启用多窗口时（如windows=[10,21,40]），同时计算多个回归窗口的动量分，按各自R²加权融合：
fused_score = Σ max(R²_m, 0) × score_m / Σ max(R²_m, 0)
短窗口捕获快速趋势，长窗口过滤噪音，融合后在不同行情节奏下都能命中。

### 筛选参数（已对齐聚宽口径）
- min_score = 0 — 剔除负分动量
- max_score = 6 — 过热阈值。注意：这不是硬上限！池内若有score > max_score的标的，则要求这些标的score_T ≥ score_{T-1} × 1.1才放行（动量持续加速）。极端情况下全部被过热过滤则放宽回原池，保证pipeline不空跑。
- score_threshold_multiplier = 1.1 — 过热标的的日间增长门槛
- dedup_by_sector = false — 板块去重默认关闭，对齐聚宽（不去重）。如需开启，每个板块仅保留分数最高的一只，但持仓不受此限制（被去重掉的持仓单独追加回末尾）。

### Action五态语义（完全无状态，不依赖本地持仓）
| Action | 含义 | 触发条件 |
|--------|------|----------|
| strong_buy | 强烈买入（动量加速） | score_T >= score_{T-1} × 1.1 |
| buy | 买入（动量向上/反转） | score_T > score_{T-1} 或 prev≤0 且 score>0 |
| hold_only | 观望（动量减速） | score_T <= score_{T-1} |
| avoid | 回避（趋势失效） | score < 0 或 R² < 0.3 |

无T-1数据时：score ≥ 0.3 → buy，否则 hold_only。

### 持仓豁免位（MustIncludeCodes）
- 用户当前持仓若已通过MinScore/过热/Regime闸门但被截到TopN之外，按其客观分数追加在结果末尾
- 被过滤剔除的持仓不出现、不插队、不抬分
- 持仓标记IsCurrentHold=true，在报告中高亮
- 持仓对照由BuildHoldAdvices生成：每只持仓独立给出HitTop、Rank、Action，不参与主决策

### 折溢价反向因子（仅实时模式：调用工具获取IOPV）
- PremiumPct >= +3.0%：Score × 0.85（严重过热）
- PremiumPct >= +1.5%：Score × 0.95（追高警告）
- 折价/正常溢价不做调整
- 只在IOPV>0时生效

### 归一化：sigmoid映射到0~100
normalized = 100 / (1 + exp(-2.5 * score))
sigmoid是score的严格单调递增函数，归一化后排名与裸分完全一致。

### 2c 技术面（TechnicalAgent）— 杰西·利弗莫尔 + 威廉·欧奈尔
对Top5每只ETF进行CANSLIM量价分析，基于实际K线指标：
- 趋势判断（up/down/sideways）

- MACD金叉/死叉/零轴位置
- RSI是否超买/超卖
- 支撑位（MA20/MA60）/压力位（前期高点/MA5上方）识别
- 建议持有区间

### 2d 宏观环境（RegimeAgent）— 达利欧 + 霍华德·马克斯
基于沪深300(510300) K线判断宏观趋势，纯规则推导：

趋势判定：
- risk_off：价格跌破MA120 且 60日回撤 >= 8%（分数=max(0,30-dd×100)）
- bear：价格跌破MA60 且 MA60 < MA120（分数=35）
- bull：价格 > MA20 > MA60 > MA120（多头排列，分数=85）
- neutral_up：价格 > MA60 但未形成多头排列（分数=65）
- neutral：其他（分数=50）

PositionCap设计原则（已对齐聚宽实战）：
- bull=1.0 / neutral_up=0.95 / neutral=0.85 — 让动量信号充分发挥
- bear=0.4 — 仍允许部分动量反弹机会
- risk_off=0.0 — 仅在MA120跌破+60日回撤>=8%时强制空仓

反向约束：
- regime.trend == "risk_off" → 强制avoid（达利欧派一票否决，硬约束保留）
- regime.trend == "bear" → 降一档（strong_buy/buy → hold）
- target.premium_pct >= +3% → strong_buy/buy强制降为hold（巴菲特派一票否决追高，仅实时模式）
- position_cap必须 <= regime给的上限

### 2e 资金面（MoneyFlowAgent）— 保罗·都铎·琼斯 + 马蒂·施瓦茨
通过工具获取：
- 北向资金5日/20日累计净流入
- ETF主力净流入数据
- 判断资金面与动量信号是否匹配
- 评分0-100

### 2f 长期记忆（MemoryAgent）
- 回顾历史分析记录（最近5份报告），识别跨日pattern：
  - 连续追高：连续>=2天strong_buy/buy同一板块且溢价率走高
  - 连续踏空：连续>=2天hold/avoid但事后动量加速
  - 板块切换：今日目标与最近2-3日不同
  - 评分中枢漂移：综合评分3日均值明显抬升或下降
  - 同标重复推荐：同一ETF被多次推荐
  - 消息面情绪转向：news_score从>=60骤降到<=40（或反之）
  - 板块消息面分化：不同板块sentiment出现明显分化
- 输出summary/patterns/warnings注入FinalAgent

## 第三阶段：投委会决策融合（FinalAgent）

模拟5位投资大师组成的内部投资委员会，融合6路信号：

1) **价值派 — 巴菲特**：关注安全边际/估值/溢价率。溢价率>=+1.5%视为追高警告（strong_buy→buy），>=+3%强制strong_buy/buy→hold，一票否决追高。
2) **反身性宏观派 — 索罗斯**：关注宏观周期/市场情绪与基本面背离/流动性拐点。
3) **趋势派 — 利弗莫尔**：关注技术面/动量/关键阻力突破/止损纪律。只在多头排列+突破前高时进攻。
4) **全天候宏观派 — 达利欧**：严格执行position_cap；risk_off必须空仓；不同板块对应不同经济周期象限。
5) **量化派 — 西蒙斯**：严格按板块自适应权重加权；不让"故事"凌驾于"数字"之上；识别"哪些因子对该板块本来就不相关"。

### 因子相关性认知（西蒙斯视角必检项）
- 海外ETF：标的资产在境外交易，北向资金/沪深300宏观影响极弱。海外指数当日走势是核心驱动，ETF自身的折溢价、量比、技术面反映场内供需。
- 港股ETF：南向资金+港股流动性+美股传导驱动，宏观影响中等。
- A股科技/新能源：北向资金+产业政策(News)+宏观风险偏好共同作用。
- 顺周期/宽基：宏观Regime权重抬高。
- 贵金属：避险资产，与美元/美债/海外避险情绪强相关，北向资金影响弱。
- 债券：利率类资产，宏观环境(利率/流动性)是主要驱动，动量与技术面敏感度低。

### FinalAgent 决策约束
- 必须在 reasoning 中至少显式提及2位委员的判据（如"趋势派看到多头排列"、"价值派提示溢价偏高"、"达利欧派指出宏观risk_off"）
- 任一 Agent 不可信时降低其权重
- reasoning 中提到的所有数字/政策/资金流必须能从输入中找到出处，不得编造
- 禁止使用"据悉/据传/可能/预计"等无来源虚词（巴菲特派的求实纪律）

### 综合评分 → recommendation映射（两套阈值）

**LLM决策（用于输出JSON时）**：≥80 strong_buy / ≥65 buy / ≥50 hold / <50 avoid

**规则兜底（LLM不可达时）**：≥70 strong_buy / ≥40 buy / ≥25 hold / <25 avoid

设计依据：底层normalizeStrategy3Score把score=0映射到50，score=0.3→~63。旧阈值会把"动量弱正向+多因子中性"的标的映射成hold，在每日状态机里等同于平仓→频繁空仓。新阈值让动量正向标的稳定进buy，对齐聚宽"rank[0]直接持有"语义。

### 跨标的相对强度校准（西蒙斯派）
- Target的news/tech score显著高于peers（高出15%+）→该因子贡献+5%~+10%
- Target显著低于peers（低出15%+）→该因子贡献-5%~-10%
- 无显著差异（±15%以内）→不做调整

### 回撤冷却闸门
- 近5日高点回撤 >= ATR自适应阈值（2×ATR14/price，clamp到[3%,10%]；ATR不可用时退化到固定5%）
- 且未收复MA5 / 最近阴线半分位
- 主信号（持仓/未提供持仓）：不降档，仅注入"【回撤冷却】"提示文案
- 备选Pick（新开仓/非持仓）：直接buy→hold
- 设计理由：单边强趋势中5日-5%回撤+MA5失守可能是正常调整，当前选择"提示而不降档"

### 盈亏比闸门
- (take-entry) / (entry-stop) < 1.4 或 entry/stop/take结构无效
- 主信号注入"【盈亏比提示】"，不降档

### 投委会精选（Picks，1~2支）
- Pick #1 = best(Top1)，必须给出"在Top5中胜出的具体理由"- 跨标横向对比
- Pick #2（可选）：板块或风格与Pick#1不同，避免双倍下注同一风险因子
- 当Top5除best外没有同时满足trend!=down且sentiment!=negative的标的时，仅返回1支
- LLM未返回picks时由规则兜底：板块分散优先、剔除negative消息面+down趋势

### 持仓评审（HoldReviews）
- 仅在用户提供持仓时输出
- 每只持仓独立评审：keep(继续持有)/trim(减仓观察)/rotate(平仓切换)
- 评审必须引用：候选量化分（绝对+与best差距）+ news_list中的sentiment + tech_list中的trend
- 离开主决策：hold_reviews不改变recommendation/picks/价格方案
- 规则兜底：avoid/trend=down/news=negative→rotate；hold_only/trend=flat→trim；其余→keep

### 价格方案
- entry_price：当前价附近
- stop_loss：MA20下方1%（或当前价×0.97）
- take_profit：基于波动率（volatility×5，clamp到4%~10%）或前高

## 第四阶段：集合竞价复核（PreOpenAgent）

用户提及"集合竞价"或"开盘前复核"时，额外执行以下流程：

1. 重新获取当前 IOPV + 溢价率（实时工具调用）
2. 对比上一份报告的评分/推荐是否仍成立
3. 若标的偏离推荐价格 >= 1% 且溢价率上升 -> adjust 建议或暂缓
4. 输出简短复核结论追加在报告末尾
